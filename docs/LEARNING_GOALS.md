# Learning Goals

This challenge series is intended to develop practical ability to:

- Translate written hardware specifications into interfaces and architecture.
- Derive combinational equations and sequential state transitions before coding.
- Write synthesizable Verilog-2001 with clear reset and timing behavior.
- Build self-checking testbenches with independently calculated expected results.
- Exercise nominal operation, boundaries, resets, and corner cases.
- Analyze simulation waveforms and isolate design bugs.
- Explain design decisions, assumptions, and verification limits.

Completion means being able to explain the design and its verification strategy, not only obtaining a passing simulation.
