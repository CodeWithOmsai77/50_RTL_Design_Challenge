# 50 RTL Design Challenges

A hands-on Verilog-2001 practice track covering 50 RTL design challenges from beginner to advanced.

## Levels
- Beginner — Projects 01–20
- Intermediate — Projects 21–40
- Advanced — Projects 41–50

## Workflow
Specification → Architecture → Logic Design → RTL → Self-checking Testbench → Simulation → Waveform Analysis → Debugging → Verification

## Tools
Icarus Verilog, VVP, GTKWave, and Verilator.

## Repository Structure
Each challenge will contain its RTL, testbench, simulation notes, and relevant design documentation.
